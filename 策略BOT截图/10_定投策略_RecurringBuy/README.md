# 定投策略 (Recurring Buy)

**截图数量**：30 张

## 策略原理

定期定额买入，分散择时压力，让长期积累更简单。分「精选专区」（AI/预设组合）与「手动创建」两条路径。

## 关键参数

- 买入币种（支持 1–20 个币种，可选数字货币 / 新币种 / TradFi）
- 每期金额（USDT）、投资额
- 定投频率（12 小时等）
- 首次买入时间：立即买入 / 自定义时间
- 选择账户、余额不足时自动赎回、其他账户自动补足、自定义扣款顺序
- 预计定投次数 = 定投可用金额 / 每期定投金额
- 买入价格区间：最低价 / 最高价
- 高级设置（自定义参数）

## 主要操作流程

1. 创建策略 → 定投策略
2. 精选专区：选预设组合 → 创建策略；手动创建：选币种 → 每期金额 → 频率 → 首次买入时间 → 账户 → 价格区间 → 创建

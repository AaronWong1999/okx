# 现货马丁格尔 (Spot Martingale / DCA)

**截图数量**：10 张

## 策略原理

现货版的分批建仓摊薄成本。价格下跌触发加仓，达到单周期止盈目标即卖出该批。

## 关键参数

- 触发条件：跌多少加仓（0.2%–50%）
- 单周期止盈目标（0.2%–1,000%）
- 初次下单金额（2–50,000 USDT）、加仓单金额（≥2 USDT）
- 最大加仓次数（0–100）、委托数量
- 投资额
- 预设开始条件：价格触发 / RSI-14 触发（指标周期、触发条件、向下穿过、超卖线、K线周期、延迟开始）

## 主要操作流程

1. 创建策略 → 现货马丁格尔
2. 选标的 → 设触发条件与止盈目标 → 预设开始条件 → 创建

## 视频覆盖说明

参数区间与合约马丁格尔不同（加仓幅度 0.2% 起、止盈目标上限 1000%）。

# 信号策略 (Signal Bot)

**截图数量**：16 张

## 策略原理

接入 TradingView 警报信号，信号触发时自动下单；可配置加仓规则、止盈止损与最大持仓数。

## 关键参数

- 信号：选择已有信号 或 新增自定义 TradingView 信号（信号名称 ≤50 字、信号简介 ≤1500 字）
- 交易对选择（最多 10 个，超出会提示「杠杆超出 1 个交易对的最高可用杠杆倍数」）
- 投资额（保证金，≥50 USDT）、距离买一/卖
- 加仓设定：占用可用保证金比例 / 实用投资额百分比 / 固定保证金 / 单次委托量（USDT）
- 止盈止损：收益率、涨跌幅
- 委托类型、最大持仓数量、自动赚币、杠杆

## 主要操作流程

1. 创建策略 → 信号策略
2. 选择信号 → 选择交易对 → 设投资额 → 加仓设定 → 止盈止损 → 创建

## 视频覆盖说明

自定义信号引导页详细说明了如何在 TradingView 设置警报消息并配置交易。

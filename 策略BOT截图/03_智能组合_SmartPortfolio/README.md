# 智能组合 (Smart Portfolio)

**截图数量**：5 张

## 策略原理

在用户选定的币种组合中做智能动态调仓，使各币种比例保持恒定。支持两种调仓模式触发调仓（定期调仓 / 阈值偏离调仓）。

## 关键参数

- 目标比例（每个标的的权重，如 BTC 5.00%）
- 调仓触发方式：定期检查权重 / 偏离达到阈值时自动再平衡
- 收益表现：回测年化收益率
- 使用人数、运行时长、跟随人数
- 创建方式：AI 策略（预设组合） / 手动创建（自选币种）

## 主要操作流程

1. 创建策略 → 智能组合
2. AI 策略选预设组合 / 手动创建选币种与比例
3. 设投资额 → 选调仓模式 → 创建

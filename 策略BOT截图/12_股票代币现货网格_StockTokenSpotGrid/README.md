# 股票代币现货网格 (Stock-Token Spot Grid)

**截图数量**：10 张

## 策略原理

锚定股票代币的波动特性，网格自动捕捉每一次起落。定位「长期稳健型」，把美股代币当作网格标的做现货套利。

## 关键参数

- 匹配标的：xMU/USDT、xSOXL/USDT、xSNDK/USDT、xNVDA/USDT、xAMD/USDT
- 回测年化收益率、累计使用人数、累计投入金额
- 年化收益率（跟单页面）
- 策略类型：稳健型 / 长期稳健型 / 中期均衡型 等

## 主要操作流程

1. 创建策略 → 股票代币现货网格
2. 选代币标的 → 选策略类型 → 创建

## 视频覆盖说明

是现货网格针对股票代币的特化版本，与 01_现货网格 的参数面板不同。

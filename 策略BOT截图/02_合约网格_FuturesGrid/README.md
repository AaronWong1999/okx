# 合约网格 (Futures Grid)

**截图数量**：28 张

## 策略原理

合约版的网格循环套利，可用杠杆放大，牛熊皆宜。多空双向吃价差，网格止损/止盈由系统管理。

## 关键参数

- 投资额（保证金）—— 校验「保证金应大于 X USDT」
- 实际保证金 + 预留保证金、含杠杆的实际投入、预估强平价
- 杠杆倍数 1x–100x（界面有 5x/10x/20x/30x/50x/100x 档位，附强平风险提示）
- 网格数量（2–1,000）、单网格收益率
- 预估买入均价 / 预估卖出均价、30 日年化资金费率
- 止盈止损：最新价、价格区间、止盈收益率
- 滑点控制、自动赚币、网格随价格上移

## 主要操作流程

1. 创建策略 → 合约网格
2. 选合约标的 → 调杠杆 → 设保证金/网格 → 止盈止损 → 创建

# 现货网格 (Spot Grid)

**截图数量**：16 张

## 策略原理

在用户指定的价格区间内按等差或等比自动铺设网格。价格每跌一格买入一仓、每涨一格卖出一仓，赚取网格之间的价差，不需要判断方向。适合震荡行情。

## 关键参数

- 投资额（USDT）—— 总投入资金，滑杆可调
- 网格数量 / 网格模式（等差、等比）
- 价格区间：最低价、最高价、各区间金额
- 单网格收益率 —— 价格区间内单个网格的预估收益率（已扣手续费）
- 利润复投 —— 网格利润是否自动复投到下一轮投资
- 自动赚币 —— 让闲置币自动产生收益，含「简单赚币分配」
- 高级设置：网格随价格上移 / 网格随价格下移
- 预设开始条件 / 预设停止条件（价格触发、RSI-14 触发、TradingView 信号、延迟开始）
- 止盈 / 止损

## 主要操作流程

1. 创建策略 → 现货网格
2. 选交易对 → AI 推荐参数 或 手动创建
3. 设投资额/区间/网格数 → 高级设置 → 预设条件 → 创建策略

# 智能套利 (Smart Arbitrage)

**截图数量**：18 张

## 策略原理

现货买入 + 合约做空（或反向）对冲价格风险；持有的现货同时质押为 OKSOL 赚取收益，叠加资金费率收益。收益构成 = 质押奖励 | 资金费收益 | 额外年化加成。也可借入 USDT 放大投资（借币会产生利息，可能影响收益）。

## 关键参数

- 套利币种：现货对 + 永续对（如 SOL/USDT + SOLUSDT 永续、xMU/USDT + MUUSDT 永续）
- 投资额（USDT）
- 杠杆、买卖方向（买现货卖合约 / 买合约卖现货）
- 排队价 / 深度图表
- 策略预览：仓位预览、收益预览、预计开仓盈亏、预计开仓价差、现货开仓手续费、预计投资额分布
- 3 日预估总年化、下次参考年化
- Crypto / Tradfi 市场切换

## 主要操作流程

1. 创建策略 → 智能套利
2. 选套利策略（SOL/xMU/xMRVL…）→ 设投资额 → 策略预览 → 下单

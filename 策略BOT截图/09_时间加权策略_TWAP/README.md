# 时间加权策略 (TWAP)

**截图数量**：6 张

## 策略原理

把总委托量按时间平均拆分成若干子单匀速执行，避免单笔冲击市场，适合大额建仓/减仓。

## 关键参数

- 价格区间（最低价 / 最高价）
- 吃单价优于盘口（USDT）、吃单限制价（USDT）
- 杠杆倍数与预估强平价
- 下单倒计时 / 运行时长

## 主要操作流程

1. 创建策略 → 时间加权策略
2. 选标的 → 设价格区间与限价 → 调杠杆 → 下单

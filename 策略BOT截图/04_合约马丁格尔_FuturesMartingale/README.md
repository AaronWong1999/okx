# 合约马丁格尔 (Futures Martingale / DCA)

**截图数量**：13 张

## 策略原理

价格每下跌一个设定幅度就按比例加仓（梯子式建仓），摊低成本；任一仓位达到单周期止盈目标即平掉该仓，用后续加仓覆盖前面的亏损。

## 关键参数

- 触发条件：跌多少加仓（0.1%–50%）
- 单周期止盈目标（≥0.1%）
- 初次下单保证金（≥1.25 USDT）、加仓单保证金（≥1.24 USDT）
- 最大自动加仓次数（0–100）
- 投入保证金、目标保证金率、预估强平价
- 下次投资使用利润复投、自动划转保证金 + 划转上限（USDT）
- 止损条件（135.78 USDT）
- 杠杆（界面出现 19x 提示「超过 10x 杠杆会增加强制平仓风险」）

## 主要操作流程

1. 创建策略 → 合约马丁格尔
2. 选标的 → AI 策略小助手推荐参数 → 调杠杆
3. 设触发条件/止盈目标/保证金 → 高级设置 → 创建

## 视频覆盖说明

视频含「AI 策略小助手」自动推荐参数（激进型 / 短期进取建仓-做空）。

# 美股代币合约网格 (Stock-Token Futures Grid)

**截图数量**：4 张

## 策略原理

拓展美股多元配置，网格全天候赚取利润。定位「中期进取型」，在美股代币合约上跑网格。

## 关键参数

- 累计使用人数、累计投入金额
- 策略类型：中期进取型
- 风险须知（股票合约不构成对股票的所有权等）

## 主要操作流程

1. 创建策略 → 美股代币合约网格
2. 读风险须知 → 选标的 → 创建

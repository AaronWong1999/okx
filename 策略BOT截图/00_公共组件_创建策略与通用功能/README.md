## 策略原理

所有策略 BOT 的共同入口与通用能力，不属于单一 bot。

## 关键参数

- 创建策略入口：热门策略 / 现货网格 / 合约网格 / 智能组合 / 定投策略 等
- 策略&跟单：推荐 / 我的策略 / 我的跟单
- 各 bot 的完整目录：现货网格、合约网格（币本位）、智能组合、信号策略、抄底止盈策略、合约马丁格尔、现货马丁格尔、股票代币现货网格等

## 主要操作流程

1. 资产页 → 策略&跟单 → 创建策略 → 选择 bot 类型

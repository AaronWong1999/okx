# 冰山策略 (Iceberg)

**截图数量**：23 张

## 策略原理

把一笔大单拆成多个小单挂单，只对外显示部分成交量，降低市场冲击与抢单风险。

## 关键参数

- 单笔委托量、单次挂单数、委托总量
- 限价方式：吃单价优于盘口（USDT）、吃单限制价（USDT）
- 方向：可开多 / 可开空
- 杠杆倍数（3.00x 等）、所需保证金、预估强平价
- 高级设置

## 主要操作流程

1. 创建策略 → 冰山策略
2. 选合约标的 → 设挂单参数 → 调杠杆 → 下单
